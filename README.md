**Операция «Переводчик поколений»** — образовательная браузерная игра и двуязычный лексикографический архив. В роли цифрового детектива игрок восстанавливает смысл сообщений студенческой IT-команды, которые экспериментальный переводчик ошибочно понял буквально.

Проект подготовлен для Всероссийского проектного конкурса по лексикографии «Переводчик с молодёжного: шпаргалка для взрослых». Это самостоятельная конкурсная работа, а не официальный сервис университета. Персонажи, переписки и ситуации вымышлены.

## Автор

Полякова Дарья Александровна, РТУ МИРЭА, группа ЭФБО-05-25, 2 курс. Направление — «Информационные системы и технологии», профиль — Fullstack-разработка. Москва, 2026.

## Что внутри

- Сюжет из трёх глав и пятнадцати заданий: поиск улик, выбор реплик, сопоставление, языковой конструктор, восстановление порядка и сборка итогового сообщения.
- Инвентарь с уликами, открытыми словами и восстановленными модулями; контекстные подсказки и объяснения решений.
- Три поддерживающих финала в зависимости от результата; прохождение не ограничено реальным таймером.
- Самостоятельный архив с русскими и английскими определениями, грамматикой, происхождением, примерами и нейтральными эквивалентами.
- Отдельные режимы «Для жюри» и «Экспресс-декодер», которые не изменяют сюжетный результат.
- Исследовательская часть с библиографией, двуязычной таблицей и печатной версией.
- Сохранение в браузере без регистрации; управление мышью, касанием и клавиатурой; настройка уменьшенной анимации.

## Как играть

На главной странице выберите «Начать расследование». После короткого брифинга примите дело и откройте доступную главу на карте. Читайте переписки, открывайте отмеченные улики, затем решайте головоломку. Подсказки направляют к ответу, ошибки позволяют попробовать снова. После каждых пяти заданий восстанавливается один модуль декодера. В конце составьте понятный отчёт преподавателю.

Полное прохождение рассчитано примерно на 12–18 минут; это проектная оценка, а не результат замера на выборке пользователей. Архив и исследование доступны независимо от игры.

## Технологии

React, TypeScript, Vite, CSS и SVG; Vitest для логики, Playwright для браузерных сценариев. Приложение статическое: сервер приложения, база данных, платные API и учётная запись игрока не требуются. Версии зависимостей фиксирует `package-lock.json`.

## Локальный запуск

Потребуются Node.js 22.12+ или 24 LTS и npm.

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Не открывайте `index.html` двойным щелчком: исходный TypeScript требует сервера разработки либо сборки.

## Проверки и сборка

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm run preview
```

Сборка проверяет TypeScript и создаёт `dist/`. Production preview нужно открывать по пути `/slang-os/`. Если PowerShell блокирует `npm.ps1` из-за Execution Policy, используйте те же команды с `npm.cmd` и `npx.cmd`; менять системную политику не требуется.

Браузерные проверки:

```bash
npx playwright install chromium
npm run test:e2e
```

Сценарии и критерии проверки описаны в [docs/TEST_PLAN.md](docs/TEST_PLAN.md). Само наличие команд не означает, что проверки выполнены: итог конкретного запуска следует смотреть в отчёте выполнения и выводе команд.

## Публикация

Репозиторий: [MrDary-art/slang-os](https://github.com/MrDary-art/slang-os).

Workflow `.github/workflows/deploy.yml` запускается при push в `main` или вручную. Он устанавливает зависимости из lockfile, запускает тесты, проверяет типы при сборке и публикует `dist/` официальными GitHub Pages Actions. В репозитории нужно выбрать **Settings → Pages → Build and deployment → Source → GitHub Actions**.

Опубликованный сайт: [mrdary-art.github.io/slang-os](https://mrdary-art.github.io/slang-os/). Сборка и публикация версии `e247a5e` подтверждены [успешным запуском GitHub Actions](https://github.com/MrDary-art/slang-os/actions/runs/43828520327) 16 ноября 2026 года: установка зависимостей, 50 тестов, ESLint, TypeScript, production build и deploy прошли на Node.js 22.

Подробности и диагностика: [docs/DEPLOY.md](docs/DEPLOY.md).

## Лексикографическая основа

В архив включены молодёжные, цифровые и профессиональные IT-единицы. Эти категории пересекаются, но не равнозначны. Подборка не объявляется репрезентативным корпусом речи студентов РТУ МИРЭА. Учебные примеры написаны для проекта. Заимствованный источник слова, современное значение и гипотеза о пути распространения описываются раздельно.

Источники и ограничения анализа собраны в разделе «Исследование» и в [docs/RESEARCH.md](docs/RESEARCH.md). Реальные опросы не подменены вымышленными процентами. [Готовая анкета с формами A/B и ключом оценки](docs/SURVEY.md) позволяет дополнить работу настоящими анонимными ответами до подачи.

## Хранение и приватность

Ключ сюжетного сохранения — `slangos_save_v1` в `localStorage`. Прогресс хранится на данном устройстве в данном браузере; очистка данных сайта удалит его. Приложение не просит имя, почту или телефон игрока и не использует стороннюю аналитику. Сброс выполняется с подтверждением и затрагивает только данные игры.

## Для подачи на конкурс

Сайт — творческая часть. Организаторы требуют также исследовательскую работу в DOC/PDF и заполненную заявку. Условия, список обязательных полей и порядок подготовки приведены в [docs/CONTEST_SUBMISSION.md](docs/CONTEST_SUBMISSION.md). Не включайте личные контактные данные заявки в публичный репозиторий.

Подготовлены [исследовательская работа](docs/RESEARCH.pdf), [бланк заявки](docs/APPLICATION.pdf) и его [редактируемый HTML-исходник](docs/APPLICATION.html). Неизвестные личные данные в заявке оставлены пустыми; их заполняет автор перед отправкой. Методика будущего сбора реальных ответов — в [docs/SURVEY.md](docs/SURVEY.md).

Откройте HTML-бланк в браузере, заполните пустые поля и сохраните через печать в PDF **в личную папку вне репозитория**. Поля HTML не отправляются и не сохраняются приложением. Не публикуйте заполненную копию или сырые ответы анкеты в GitHub.

Воспроизводимый экспорт исследования из production-сборки:

```bash
npm run build
npm run research:pdf
```

Скрипт создаёт `docs/RESEARCH.pdf` и при необходимости запускает локальный preview. Требуется Chromium Playwright либо установленный Edge/Chrome. После экспорта просмотрите все страницы перед отправкой.

Для повторного экспорта бланка заявки выполните `node scripts/export-research.mjs --application`. Данные, введённые только в открытой вкладке HTML, не сохраняются автоматически: для них используйте печать из этой вкладки или сохраните изменения исходника. Не фиксируйте заполненный бланк с личными данными в публичном репозитории.
